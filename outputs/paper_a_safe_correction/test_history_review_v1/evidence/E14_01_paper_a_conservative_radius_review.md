# A03/B04/D08：保守性与半径的补充分析协议

2026-09-11。分析开始前固定下述范围；这是看过历史 TEST 后的问题驱动分析，不宣称新的盲测确认。原 ADC/DynaSemble DEV 锁、模型与 TEST 结果均不修改。

1. “Conservative”只指 reference-anchored、bounded-action：围绕已锁参考权重调整，且逐查询权重偏移不超过所给半径（对本项目对齐网格成立）。它不承诺少干预、较小 RR 损害、损害概率上界或支配 Global。
2. 统一报告相对同一 Global 的净效用 `E[ΔRR]`、损害频率 `Pr(ΔRR<0)`、条件损失 `E[-ΔRR|ΔRR<0]`、无条件损失 `E[max(-ΔRR,0)]`、无条件收益及答案排名改变率。另报告同一 z-score 权重坐标中的动作率 `Pr(alpha!=alpha0)` 和平均偏移。DynaSemble 使用 min-max 坐标，其比例不能直接减去 z-score Global 权重；相应动作率标为不适用，答案排名改变率仍可比较。Global 的损害与干预均为零，条件损失无定义。
3. DEV 使用修正后的 `information_boundary_v2` 导出。完整 DEV 已锁模型上的 β×τ 网格属于 resubstitution 描述，明确标注。β取0以及0.05至1.00、步长0.05；τ取0、0.1、0.2、0.3。β=0仅作为Global对照，不混入原先非零半径的选参规则。
4. 另以原三元组五折重建已有13维逻辑回归（仅20个轻量折模型，不重训基座），保持原折、种子、预处理、anchor与标签。首先要求复现原 P3 的 held-out α、RR、fallback及训练部分选参；不通过则停止，不能悄悄替换原结果。每折分别在训练部分以MRR选择 cap=.50 与 cap=1.00 两个有限家族，固定同一 τ 网格与 tie-break，再在 held-out 部分报告共同指标。增加固定 β 曲线时，τ沿用该折原受限选择；曲线不用于 TEST 选参。聚合DEV曲线用于描述经验取舍，不宣称选后无偏最优性。
5. TEST 只重构原锁ADC、Global、Query-soft、Relation、β=1、τ=0及已有R0/R1/R2/R3-fixed/R3/R4结果。所有seed保留，使用实际selector观测计算损害；不对selector先取平均后计算损害。不用新DEV曲线挑选任何新TEST策略。
6. 报告所有预定点及经验非支配关系，不据结果挑风险指标。DEV上效用更低且无条件损失更高的点不得称为优选。比较是描述性的，不新增大bootstrap或概率风险保证；既有主效应区间不被重新解释为风险保证。
7. 无可核验的“0.50对应某个风险水平”的历史证据时，应明确称其为设计时限定的搜索族上界，而非补造先验风险理由。宽家族也只是所检有限网格，不是全局最优。
