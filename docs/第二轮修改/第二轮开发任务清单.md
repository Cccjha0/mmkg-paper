## 2.3 `scripts/summarize_delta_scan.py`  （E5）

### 目标

### 依赖
- 各 `delta` 下的 threshold scan CSV
- 各 `delta` 下的 dev label 统计
- 可选：对应的 oracle gap 结果

### 开发任务
- [x] 明确输入接口：`--scan-files --label-stats --out`
- [x] 读取不同 `delta` 的 threshold scan CSV
- [x] 为每个 `delta` 选出最优 `tau`
- [x] 汇总每个 `delta` 的：
  - [x] `selected_tau`
  - [x] `best_mrr`
  - [x] `fusion_coverage`
  - [x] `gain_precision`
  - [x] `positive_label_rate_dev`
  - [x] `oracle_gap_at_best_tau`
- [x] 生成统一 summary 表
- [x] 可选：输出一段自动生成的结果摘要文字

### 输出文件
- [x] `outputs/router/analysis/delta_scan_summary.csv`

### 验收标准
- [ ] 三个 `delta` 都有记录
- [ ] 每个 `delta` 的最优 `tau` 明确
- [ ] summary 能清楚支撑：
  - [ ] `delta=0.00` 太松
  - [ ] `delta=0.02` 太严
  - [ ] `delta=0.01` 平衡最好
- [ ] 论文中能据此增加一句正式 configuration selection 说明
