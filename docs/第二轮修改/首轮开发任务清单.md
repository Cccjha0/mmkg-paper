# MMKG Paper 首轮开发任务清单（按脚本逐项勾选）

> 目标：完成首轮 **routing / regime / oracle** 分析闭环，为论文中的 RQ1 / RQ2 / RQ3 补齐最关键的新实验。  
> 当前仓库已经具备主模型 3-seed 结果、router 主叙事、threshold scan、feature ablation、subgroup / relation-group 分析，因此首轮开发重点应从“补模型训练”转向“构建统一 query-level 分析管线” :contentReference[oaicite:0]{index=0}  
> 同时，后续所有新增分析必须继续遵守论文当前已写明的两条 evaluation line 分离原则，以及 dev-only router training / test-only final reporting 的协议约束 :contentReference[oaicite:1]{index=1}

---

## 0. 首轮开发范围

本轮只做以下两类内容：

### A. 核心数据与评估管线
- query-level outcome 导出
- relation prior 构建
- router feature table 构建
- router 训练
- threshold scan 评估
- unified master table 构建

### B. 论文最关键新增分析
- E1. Per-regime win-rate
- E2. Per-regime oracle upper bound
- E6. Per-regime routing behavior
- E7. Oracle gap decomposition

> 暂不纳入首轮：
> - E3 XGBoost feature importance
> - E4 Logistic top coefficients
> - E5 δ scan summary
> - 统一论文绘图脚本美化
>
> 这些可以作为第二轮解释性增强内容。

## 2.1 `scripts/export_query_level_outcomes.py`

### 目标
为 `Gate-only`、`Residual-only`、`Full Model` 导出统一格式的 query-level outcome 表，作为后续所有 routing / regime 分析的底层输入。

### 依赖
- 已有模型 run 目录
- 各 run 下可读取 test / dev 的 query 级评估结果或可复算 rank / RR / score / margin 的数据

### 开发任务
- [ ] 明确输入接口：`--run-dir --split --model-name --evaluation-line --out`
- [ ] 支持 `split ∈ {dev, test}`
- [ ] 支持 `model-name ∈ {gate_only, residual_only, full_model}`
- [ ] 支持 `evaluation-line ∈ {routing_compatible, official}`
- [ ] 从 run 中读取 query 级 rank 结果
- [ ] 统一生成 `query_id`
- [ ] 导出 `direction`
- [ ] 导出 `relation_id`
- [ ] 导出 `target_entity_id`
- [ ] 导出 `target_has_img`
- [ ] 导出 `target_regime`
- [ ] 导出 `rank`
- [ ] 导出 `rr`
- [ ] 导出 `correct_score`
- [ ] 导出 `top1_score`
- [ ] 导出 `top2_score`
- [ ] 导出 `margin = top1_score - top2_score`
- [ ] 导出 `source_run_dir`
- [ ] 导出 `source_seed`
- [ ] 输出 parquet 文件到 `outputs/router/raw/`

### 输出文件
- [ ] `outputs/router/raw/dev_gate_only_query_outcomes.parquet`
- [ ] `outputs/router/raw/test_gate_only_query_outcomes.parquet`
- [ ] `outputs/router/raw/dev_residual_only_query_outcomes.parquet`
- [ ] `outputs/router/raw/test_residual_only_query_outcomes.parquet`
- [ ] `outputs/router/raw/test_full_model_query_outcomes.parquet`

### 验收标准
- [ ] 三个模型均能成功导出
- [ ] `query_id` 在同一 split 内唯一
- [ ] `target_regime` 只出现：
  - [ ] `head_has_img`
  - [ ] `head_no_img`
  - [ ] `tail_no_img`
- [ ] `rr = 1 / rank`
- [ ] `margin >= 0`
- [ ] 不混淆 official line 与 routing-compatible line
