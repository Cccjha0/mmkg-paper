## E03：全局条件与局部强弱分开

所有六 pair 均满足已有 DEV 可靠主模型规则，没有全局不满足规则的对照，因此无法检验必要性。D-N 的 DEV/TEST 净增益点估计略负且区间跨零，也不能把规则写成保证正增益。定义、Discussion、Conclusion 已统一为研究范围，保留 C07/C08 的后验地位。

新协议先固定 ±0.005 MRR 的解释性区间与 50 个训练三元组门槛。每个原外层 fold 只用另四折估计关系×方向的三 seed 平均端点差距；按该训练估计分为次模型占优、接近、主模型占优、支持不足。holdout 分配接口只有关系和方向，没有 gold ID 或结果。模型、动作和参数都不变；不是新的部署筛选器，也没有声称 query key 跨折隔离。

- 训练层名不一定在 holdout 保持：D-NA 的训练次模型占优层 holdout 差距反为 +0.047887。表头明确层名描述训练估计，正文不将其称为实际 holdout 次模型占优。

## 解释证据与不能归因的部分

两对的 DEV endpoint-oracle−best single 为 .038671/.045779，TEST 为 .039312/.044812；TEST 21-grid oracle−Global 为 .050363/.057588。存在答案感知的机会，不能把零增益归因为“没有互补性”，也不能把 oracle 当可实现动态收益。

原 margin 的非平局端点 winner AUROC 为 DEV .543/.528、TEST .538/.523。这是描述性判别点值，没有新置信区间；它不等于 anchor 改善信号、自然胜率校准或伤害概率。不能据此分解特征不足、标签错位与估计误差的因果贡献。

关闭阈值后，TEST 净增益为 −.003250/−.000663；直接 full−no-gate 为 +.003389 [.002211, .004592]、+.000649 [.000360, .000944]。因此在固定原提案下，拒绝动作改善结果。等实际干预量后，两个 TEST 差距为 +.000315 [−.000053, .000695]、+.000078 [−.000050, .000204]，均未解决；DEV 中 D-NA 等量对照仍为正，W-NA 区间跨零。这些结果不证明 gate 最优，也不把减少干预数量包装成已证实的选择信息收益。
