# E05/E06：绝对分组指标与两基准范围核查

E05 按“方向绝对指标＋TRAIN 预定义关系组＋完整支持和负结果”处理。E06 明确选择更窄的主张：可靠 primary 范围内、两个基准、六个固定 pair 的后验研究。OpenBG-IMG 仍为发现阶段，不能合计成三个独立确认集。本轮不增加数据集或未见 pair，不需要服务器计算。

## 分组方式与支持口径

在读取分组结果前，协议固定频数桶：有效 TRAIN 中 0、1–99、100–999、至少 1,000 条三元组。另固定每个数据集 TRAIN 支持最多的五个关系，按支持降序、canonical relation ID 升序打破 tie，其余关系归 Other。没有按 TEST 收益排序或只展示正结果。

分组依据来自 C01–C03 的 canonical split ledger，重新拼接 TRAIN 并验证既有 SHA-256。MKG-W 有效 TRAIN 为 34,196，DB15K 为 71,300（从原 79,222 中划出 7,922 DEV 后）。448 个关系 ID 全部保留；TRAIN 零支持并非缺失映射。频数桶只描述训练支持，不宣称语义族或因果机制。

T 为原三元组支持，单方向 N=3T，合并 head/tail 时 N=6T。它们不是独立 observable query key 数量。DEV 使用原外层 holdout 的 Global/ADC，不用全 DEV 拟合值冒充 OOF。所有绝对指标等权汇集三 seed observation；不新增分组显著性检验。既有成对区间和 seed 波动另保留。

## 关系贡献及不利结果

固定 TRAIN Top5 为 MKG-W 的 P161/P31/P57/P86/P54；DB15K 的 type/starring/birthPlace/genre/seeAlso。正式表给 canonical ID、原始 IRI 的末段和 TRAIN 支持数，完整 IRI 留在 CSV；没有猜测额外语义标签。

- W-A 的 P161、P57、P54 TEST 条件增益分别为 −.000468、−.001182、−.000500，全部与其支持及绝对 MRR 同列，未因整体为正而隐藏。
- D-N 的低频 1–99 桶与高频 ≥1,000 桶增益均为负；D-NA 的 100–999 桶也为负。全频数桶保留，而非展示最有利的桶。
- D-A 的 seeAlso（TRAIN 排名第 5）有 363 个 TEST 三元组，占 3.67%，Global/ADC MRR 为 .3631/.3675；对整体 Δ 的贡献约 +.000163，整体为 +.000212。这说明其正点估计集中在特定关系，而非普遍覆盖关系。
- TRAIN Top5 覆盖 MKG-W TEST 41.39%、DB15K 36.50% 的观察。W-N Top5 的无条件正收益份额为 36.53%、损失份额 35.95%；D-A 则为 69.96% / 39.04%。没有把净增益接近零时的比例当稳定集中度指标。
- DB15K 的 6 个 TRAIN 零支持关系有 7 个 TEST 三元组、42 个 seed×方向观察，DEV 无观察；MKG-W 的 1 个 TRAIN 零支持关系在 DEV 有 1 个三元组、6 个观察，在 TEST 无观察。空组均值记为未定义、贡献为零；这些小组不是新的独立外部验证。

每个完整分区都验证 `C_g=(N_g/N_all)Δ_g` 且 `ΣC_g=Δ_all`，并验证 ADC−Global 与无条件 gain−loss 一致。Top5 与 Other 的贡献也恢复总量。报告均为描述性，不作因果或新的显著性结论。

## E06 范围选择

`scope_decision.json` 明确记录 `narrow_two_benchmark_retrospective`。摘要、setup、分组结果、Discussion 和 Conclusion 均限定当前两基准、可靠 primary、固定六 pair；两个附加 pair 复用相同数据集，不扩展独立基准数量。OpenBG 数值仍不在修正版结果内。

本轮没有完成更强外部验证。若以后主张广泛跨 benchmark 稳健性，需要在真正未用于开发的数据集／pair 首次评价前留下完整设计冻结。新增分组表或在已经查看的 TEST 上再次运行，不能替代该证据。

## 审计与交付

复用源哈希绑定的描述性小缓存；分析约 2.3 秒，零 scorer runs、零 selector fits。对账 474,732 条观察，输出 24 个方向单元、120 个关系分组、240 个关系组×方向单元、5,229 个单关系／方向单元、448 个映射及 12 个集中度单元。单关系明细用小型确定性 gzip 保存。

三项单测覆盖 TRAIN 分桶边界/ID tie、加权绝对指标与负贡献、空组及支持分母。正式论文新增八张表；完整源码、协议、来源和统计表由 `group_scope_source_manifest.json` 绑定。交付检查包括统一论文核验、LaTeX 编译与修改页 PDF 视觉检查。
