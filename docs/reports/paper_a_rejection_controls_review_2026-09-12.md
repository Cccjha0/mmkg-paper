# B17/B18：等干预拒绝对照与 fallback 的直接成对效应

本轮补齐分析，但不支持把结论增强为“confidence 具有普遍独立的选择价值”或“fallback 对所有 pair 必需”。固定原策略后，W-N/W-A/D-A 的部分收益超出单纯减少干预次数；控制方向及位移分布后，大部分差距消失，简单 margin 规则还有更好的结果。论文已据此降调，并保留所有不利证据。

本轮复用修正后的六个 pair、原 OOF DEV 模型状态和原 TEST locks；没有新拟合、新基础模型评分、TEST 调参或挑选随机 seed。单 CPU 线程计算约 86 秒，无需服务器重训。

## B17：匹配的是实际非零干预

候选池仅含原半径、裁剪和 0.05 投影后仍然非零的未门控提议，排除了“名义保留但因 primary clip 到 1 实际没动作”的混淆。保留就执行原提议，拒绝就回到原 anchor。

拒绝单位为 `(base seed, 原拟合 fold, direction, relation, known entity)`。同一拟合对象下，相同可观测 query 的全部重复请求共用一个决定；不按指定 gold 分别抽签。替换未知 gold 后分组及动作不变，未将 RR、winner 或 harm 用于分组、优先级或预算。

按 base seed × 原 fold × 可观测 query 的重复次数分层，每层保留与 full ADC 相同数量的整组 query。由于层内重复次数相同，每一次真实随机抽样及每个固定规则都严格匹配**观察级非零干预次数**，而非仅匹配期望值或门控前 coverage。重复次数来自请求中的已知 query 键频率，无需知道目标答案。

所有对照保持原 anchor、半径、提议权重、数据与评分预算：

- **Random-I**：各层均匀随机拒绝，固定实际干预次数。
- **Head-first / Tail-first**：仅方向排序，两个方向都报告。
- **Low-A-gap**：优先原始未过滤 primary 分数的较小 top-1/top-2 gap，以其 population std 归一化。
- **Gap-agree**：优先提议所偏向专家的归一化 gap 优势；向上修正用 gap_A−gap_B，向下用 gap_B−gap_A。
- **Random-shape**：在 Random-I 的约束外，再固定 direction × 带符号的 0.05 网格位移直方图；每次实现同时匹配实际干预次数及平均 `|Δα|`。

四个简单规则事先固定，无新 learner、参数搜索或结果导向的规则选择。方向/分数相同时使用固定的、由可观测键排序得到的随机次序。它们是给定 batch 和 full 干预预算的诊断对照，不是独立选参的流式部署策略。预算是原 full 动作提供的，不能据此宣称简单规则已经替代完整 selector 或具有独立的部署效率优势。

随机行报告**随机 gate 结果的精确期望**，不是把期望权重送去排名；每个 query unit 的保留概率是层内 k/n。另报告每种随机 gate 的 2,000 个实现的 2.5/97.5 分位区间，作为随机拒绝身份造成的波动。没有挑选某次较好的抽样。

以下为 TEST 上 ADC 减随机对照的 RR 效应。括号为对差值作 2,000 次原始三元组 cluster bootstrap 的条件 95% 区间。

| Pair | 等干预 Random-I | 等干预、方向及位移 Random-shape |
|---|---:|---:|
| W-N | +0.000666 [0.000259, 0.001081] | +0.000062 [−0.000126, 0.000257] |
| W-A | +0.000359 [0.000069, 0.000673] | −0.000070 [−0.000195, 0.000047] |
| D-N | −0.000021 [−0.000147, 0.000105] | −0.000018 [−0.000066, 0.000030] |
| D-A | +0.000248 [0.000109, 0.000416] | +0.00000205 [0.00000054, 0.00000406] |
| W-NA | +0.000315 [−0.000068, 0.000708] | −0.000038 [−0.000199, 0.000123] |
| D-NA | +0.000078 [−0.000047, 0.000199] | +0.000014 [−0.000071, 0.000093] |

因此，数量减少本身不能解释 W-N/W-A/D-A 相对 Random-I 的全部收益。但在 Random-shape 中，六个 TEST pair 有五个区间跨零；D-A 残差只有约 2×10⁻⁶ RR。其 16,977 个合格 query units 中，只有 125 个落在可以更换拒绝身份的混合 strata，其余受方向/位移约束确定。这个结果支持大部分差距与动作幅度、方向的选择相关；不能把它写成独立 confidence 信息的普遍优势。

不利的简单规则结果也保留：在同样实际干预率下，W-A 的 Low-A-gap 净收益为 **0.001414**，高于 ADC 的 **0.001014**，无条件损失为 **0.000825**，低于 ADC 的 **0.001425**；ADC-minus-rule 区间为负。D-NA 的 Low-A-gap 净收益为 **0.000221**，ADC 为 **−0.000015**，且该规则损失更低、成对区间也为负。没有根据这些 TEST 结果改用该规则。

完整 DEV/TEST 表包含所有七种等干预方案，报告 U、H、无条件损失、干预率、平均绝对位移及 ADC-minus-rule 区间；随机波动另外列示。简单规则与随机对照的效果并非统一正向，不作“ADC 优于所有拒绝规则”的表述。

## B18：直接比较 full 与 no-fallback

旧稿“两个 NativE pair 的 τ=0”已不适用于修正版本。当前 W-N/W-A/D-N/D-A/W-NA/D-NA 的 TEST τ 分别为 **0.1/0.1/0.2/0.3/0.2/0.1**。所有其他参数固定，no-fallback 只把 τ 改为 0；它仍有 tanh、裁剪、投影及零动作。τ=0 本身就与该反事实相同，不提供独立的 gate 增益。

|---|---:|---:|
| W-N | −0.000059 [−0.000549, 0.000427] | +0.000010 [−0.000444, 0.000483] |
| W-A | +0.000398 [0.000117, 0.000691] | −0.000033 [−0.000339, 0.000268] |
| D-N | −0.000066 [−0.000302, 0.000175] | +0.000066 [−0.000120, 0.000260] |
| D-A | +0.002136 [0.001581, 0.002663] | +0.003201 [0.002660, 0.003759] |
| W-NA | +0.003540 [0.002423, 0.004681] | +0.003389 [0.002262, 0.004605] |
| D-NA | +0.001032 [0.000716, 0.001355] | +0.000649 [0.000364, 0.000937] |

W-N/W-A/D-N 的 TEST gate 效应均未明确偏离零，W-A 点估计还略负；D-A 是主 pair 中最明确的正效应。两个附加 pair 的 gate 效应为正，仍不等于其 full 策略可靠优于 Global：先前 full-minus-Global 区间均跨零。缓解较差的未门控提议与创造可靠的 anchor 增益是不同问题。

摘要、§6.6 和 Discussion 现均说明 fallback 的作用具有条件性。正文主表直接列出以上 12 个差值及区间，保留各策略的实际干预率与原阈值；不是把两个相对 Global 的区间间接作比较。

## 区间与核验范围

所有成对区间以**原始三元组**为抽样单位，保留对应的三 base seeds × 双方向；不按行独立抽样。随机对照的成对区间比较 full 与随机 gate 的精确期望，随机实现范围另列，两者不可混用。区间条件于已有模型、OOF 划分以及固定观察 batch 的控制分配/预算，bootstrap 时不重训或重新分配；不含新 workload、训练/选参的不确定性，也没有多重比较校正。

本轮 9 项单测检查整组 query 决定、行序不变性、重复次数加权的精确干预预算、方向/位移匹配、随机期望与枚举对照、空/全保留、no-gate 的投影/裁剪零动作及成对 cluster 抽样。全量核查 474,732 条原策略权重/RR、gold 替换后的可观测分组、实际配额和 signed/direction 直方图，并与 B15/B16 数值逐项对账。

数值目录：`outputs/paper_a_safe_correction/rejection_controls_v1/`，含 `matched_summary.csv`、`paired_fallback.csv`、`randomization_spread.csv`、`original_settings.csv`、完整 576 个联合 cell 的 `seed_direction_cells.csv` 以及审计回执。协议为 `docs/protocols/paper_a_rejection_controls.md`，源码入口为 `scripts/analyze_paper_a_rejection_controls.py`，来源及四张正式表由 `paper_a_draft/rejection_source_manifest.json` 绑定。
