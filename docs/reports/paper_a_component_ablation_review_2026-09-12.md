# E02：固定设置的组件消融与等干预比较

本轮补齐“组件难以分离”的对照缺口，但结果不支持四个组件在所有 pair 上都有必要，也不能把结果解释为可加的独立因果贡献。新增诊断使用六个 pair 的原始 grouped OOF DEV 和冻结 TEST，共 474,732 个观察；原分类器、β、τ、anchor、score/evaluator 与 0.05 投影不重新选择。计算约 105 秒，CPU 单线程，无基础模型评分或训练，无需服务器任务。

## 对照如何分开

记 a=原 anchor，b=原 β，p=σ(g)。所有拒绝和异常输入均返回 a，裁剪及投影 tie-break 相同。

| 问题 | 控制变化 | 固定部分与限制 |
|---|---|---|
| 提案中心有什么作用 | `a+b*tanh(g)` → `0.5+b*tanh(g)` | 同 b、τ、信号；fallback 与投影仍用 a。这是提案中心敏感性，不是完全移除 anchor 信息 |
| tanh 的映射形状有什么作用 | `tanh(g)` → `2p−1` 或 `clip(g,−1,1)` | 同 a、b、τ；Linear-p 的局部斜率较小，Clip-g 在零点与 tanh 斜率相同 |
| 简单线性收缩如何 | `(1−b)a+bp`，固定 λ=b | 同分类器和 gate；收缩方向、目标和实际幅度包络不同，不能称纯形状消融 |
| 半径有什么作用 | b → 1 | 原中心、tanh、gate 不动 |
| fallback 有什么作用 | τ → 0 | 原中心、tanh、半径不动 |

八种原生策略（含 ADC、Global）各只评价一个声明配置，不再为新映射搜索参数。与此前六个家族各 41 候选、DEV 各自选参的实验分开：本轮回答固定原 ADC 设置下的组件作用；此前实验回答给邻近方法调参机会后的竞争力。原 ADC 设置可能对本轮比较有利，不能把固定参数结果当作每族最优结果。

所有映射按可观测 `(seed, fitted fold, direction, relation, known entity)` 单位执行。同一 query 多 gold 记录使用同一权重。已知的小数值导出漂移通过单位内平均 g 处理；原 ADC、原 no-gate 和原 expanded-radius 的投影动作仍逐行**精确一致**，RR 同样一致，没有修改原结果。

## 等实际干预次数

对 ADC 与每个变体分别匹配。在 `(seed, fold, 可观测重复次数)` 层内，取两侧原实际非零 unit 数的较小值 k，各自均匀保留 k 个整组 query。每次真实实现两侧的非零观察数完全相同。报告每侧保留概率 k/n 作用于原离散动作后 RR 的精确期望，不把平均权重拿去排名。

每个比较有自己的预算；保留单位身份、方向、幅度不要求相同。匹配行不是同一套新 ADC，也不是部署策略。保留原数量、共同数量、各侧保留比例和 9,396 条完整分层配额。给定原模型与当前 workload 的配额在 bootstrap 中固定，不重新选择。

全部 144 个效应（六比较×两种预算×六 pair×两 split）采用 10,000 次共同原三元组聚类 percentile bootstrap，保留三 seed×双方向。区间条件于原模型、折和当前配额，不包含训练、选参或新 workload 不确定性，未作多重比较调整。下表都是 ADC 减变体；跨零不表示等效。

## 1. 提案中心：有条件的作用，不是普遍必要

| Pair | Native ADC−Center-0.5 [95% CI] | 等干预 ADC−Center-0.5 [95% CI] |
|---|---:|---:|
| W-N | +0.000368 [−0.000342, +0.001070] | +0.000368 [−0.000342, +0.001070] |
| W-A | +0.008647 [+0.007161, +0.010128] | +0.002032 [+0.001361, +0.002704] |
| D-N | +0.001638 [+0.001164, +0.002102] | +0.000518 [+0.000214, +0.000826] |
| D-A | −0.000098 [−0.000189, −0.000015] | +0.000044 [−0.000026, +0.000119] |
| W-NA | +0.000128 [−0.000288, +0.000508] | +0.000128 [−0.000288, +0.000508] |
| D-NA | −0.000433 [−0.000754, −0.000116] | −0.000529 [−0.000811, −0.000248] |

W-A、D-N 的原参照中心优势在数量匹配后仍保留，DEV 匹配效果也为正。W-N 与 D-A 匹配结果未明确偏离零；D-NA 的 TEST 结果反而支持 neutral center，DEV 区间跨零。D-A 的 native neutral-center 效用更高，同时无条件损失 0.000147 高于 ADC 的 0.000048，干预率 3.642% 高于 0.449%。不能只报其 MRR 或只报 ADC 的较低损失。以参照为提案中心的作用具有 pair 条件性，也不等于对任意其它中心的全局最优性。

## 2. 映射形状与简单收缩

在 TEST 的六个 pair 上，Linear-p、Clip-g 与 ADC 的实际干预次数本来就相同，等干预匹配保留双方 100%。因此这些差异不是由干预数量造成。

- 固定 b、τ 后，ADC−Clip-g 在 W-N 为 +0.000029 [−0.000328,+0.000384]，W-A 为 −0.000248 [−0.000399,−0.000116]，D-N 为 −0.000013 [−0.000034,+0.00000044]，D-A 为 −0.000028 [−0.000052,−0.000010]。两附加 pair 的区间也跨零。**没有建立 tanh 的独特优势**；W-A/D-A 的固定设置 Clip-g 仍有更高效用。此前 DEV-tuned Clip-g 的 W-N 半径为 0.50，本轮沿用 ADC 的 0.45，两者不可混用。
- ADC−Linear-p 在 W-N 为 +0.000835 [+0.000032,+0.001642]，D-A 为 +0.000108 [+0.000035,+0.000203]；W-A、D-N 和两附加 pair 的 TEST 区间跨零。较大的 tanh 响应在部分 pair 增加收益，也增加损失：W-N 无条件损失为 ADC 0.005463、Linear-p 0.004521。固定设置 Linear-p 在 D-N 的效用点为 +0.000054，ADC 为 −0.000081，但二者差值区间跨零。
- 对固定 λ=b 的简单收缩，等干预 ADC 增量在 W-N/W-A/D-A 分别为 +0.001022/+0.001810/+0.000079，区间为正；D-N、W-NA 区间跨零；D-NA 为 −0.000225 [−0.000401,−0.000053]。D-A 的 DEV 匹配收缩差值仍跨零，不能称稳定跨 split 优势。这是共享参数下的敏感性，不能替代此前 DEV 调参的 Shrink/Shrink-gate 强对照。

## 3. 半径：减少位移和损失，准确率有取舍

TEST Radius-1 与 ADC 在六个 pair 上具有相同非零干预数，匹配不改变结果。ADC 在全部六 pair 的平均位移和无条件损失更低，不能将此称为更少干预。例如 W-A 的 I 都为 20.293%，D 从 0.080017 降到 0.040039，损失从 0.002575 降到 0.001425；同时 ADC−Radius-1 为 −0.001170 [−0.001729,−0.000623]。

W-N、D-N、W-NA 的 TEST 差值区间跨零；W-A、D-A、D-NA 的较小半径有负向效用区间。DEV 中 D-N 反而有正向效用区间，其它 pair 取舍不同。上界限制动作与分数扰动，不提供 RR 风险保证，也不能据 TEST 选新半径。

## 4. Fallback：数量效果与选择效果分开

固定 b 仅将 τ 改为 0，原生 TEST gate 效果只在 D-A 这个主 pair 明确为正：+0.003201 [+0.002653,+0.003754]；W-N/W-A/D-N 的区间均跨零。两个附加 pair 的原生 gate 效果也为正，但原 ADC 对 Global 的效果仍未确定。

等干预后 ADC−No-gate 在 W-N/W-A/D-A 分别为 +0.000666/+0.000359/+0.000248，区间为正；D-N 和两附加 pair 区间跨零。此时 No-gate 是对其原非零提议均匀抽取同数量动作的期望，数值与先前 Random-I 的全部 12 个点一致（最大误差约 3.1e-19），不是另一种阈值训练。

D-A 匹配仅保留未门控侧原干预的 1.037%，全 gate 差值从 0.003201 缩至 0.000248；这是两个不同估计量，不能把差值直接当因果贡献比例。此前 Random-shape 几乎消除大部分剩余差距，方向/幅度与 confidence 仍耦合，不能从等次数 alone 得到独立风险识别能力。

## 核验与交付

6 项单测通过，覆盖中性中心与原 anchor 相等的退化情况、fallback 保留、单独改半径/阈值、线性收缩方向、非有限保护、整组整数配额、随机期望枚举、零配额和三种风险分母。原三条 action/RR 路径精确回放；原 TEST ADC−β1／ADC−no-gate 的 12 个点和 95% 区间逐项重现 `query_pair_v1`，没有改写任何历史产物。

结果目录 `outputs/paper_a_safe_correction/component_ablation_v1/` 保留 96 个原生策略结果、576 个 seed/direction 单元、144 个成对效应、36 个原始设置与 9,396 条匹配配额。正式论文新增设计表、DEV/TEST 直接效应表和主/附加 pair 的损失—动作表，共五表，绑定协议、代码与来源哈希；沿用 PDF 编译、视觉检查和完整核验流程。
