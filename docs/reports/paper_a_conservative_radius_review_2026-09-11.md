## 2. A03：可检验定义与不能推出的结论

Conservative 在全文只指 **reference-anchored、bounded-action**：存在已锁定的参考 α₀；fallback 返回该参考；本实验中每个应用权重满足 `|α̂−α₀|≤β`。连续规则天然满足约束；当前 α₀、β 与 0.05 网格对齐，最近点投影仍满足约束。

混合分数满足 `s_α−s_α₀=(α−α₀)(s̃_p−s̃_s)`，因此候选分数扰动最多为 `β|s̃_p−s̃_s|`。这不是独立于分数分歧的绝对分数上界，更不是 RR 损失或损害概率上界。测试构造了规范化分数的近似平局：偏移仅 `10^-6`、逐候选满足分数约束，gold RR 仍由 1 变为 1/2。

由此不使用“基本无害”“很少改动”“风险预算已校准”或“概率安全保证”等推论。标题中的 Conservative 在摘要首次出现时定义，方法 §4.4、结果、讨论与结论采用同一含义。较低损害的经验陈述必须同时指定比较对象与指标。

统一指标如下，均相对同一配对、同一观测的 Global RR：

| 指标 | 定义 | 解释 |
|---|---|---|
| U | E[ΔRR] | 净效用，即 ΔMRR |
| H | Pr(ΔRR<0) | 受损频率 |
| C | E[−ΔRR \| ΔRR<0] | 条件损失；无受损观测时不定义 |
| L₋ | E[max(−ΔRR,0)] | 无条件平均损失，包含全部观测的零值 |
| L₊ | E[max(ΔRR,0)] | 无条件平均收益；U=L₊−L₋ |
| Iα | Pr(α̂≠α₀) | 同一 z-score 权重坐标的改变率 |
| Dα | E[\|α̂−α₀\|] | 全部观测的平均权重偏移 |
| J | Pr(ΔRR≠0) | gold 答案排名改变率，不代表完整候选排序改变率 |

`L₋=H×C` 在 H>0 时成立；Global 的 U、H、L₋、Iα、Dα、J 都为零，C 无定义。对重复 selector 必须先按真实 RR 观测算损失再汇总，不能先平均预测以抵消异号损失。代码用 `10^-12` 区分数值零；当前有限候选严格排名的非零 RR 差大于该容差。

DynaSemble 使用 min-max 分数，ADC/Global 使用 z-score。不能直接把 Dyna 的主模型系数比减去 α₀，所以它的 Iα、Dα 标为不适用。U、H、C、L₋、L₊、J 仍可用共同 Global 参考比较。

## 3. B04：DEV 取舍，而不是追认最优半径

没有找到“0.50 对应某个容许风险水平”的可核验依据，因此明确把它写成历史设计中的搜索族上界。原选择是 **在 β≤0.50 的非零半径有限族内最大化 DEV MRR**。补分析不补造先验风险理由，也不宣称 β≤1.00 的更宽有限网格为全局最优。

[分析协议](../protocols/paper_a_conservative_radius_review.md)在本轮计算前记录范围，并承认此前已查看历史 TEST。只在 CPU 重建 20 个原五折、13 维逻辑回归模型。以下条件全部通过才继续比较：原三元组分折、训练折 anchor、原 β/τ 选择、留出折应用权重、RR、fallback 与 Query-soft RR 重现。原 ADC DEV 排名沿用 TRAIN∪DEV∪TEST 事实集合做 filtered evaluation；这与严格 DEV Dyna 控制的过滤范围不同。本轮没有把 TEST 三元组加入监督，也没有让过滤集合进入特征，不能将两套 DEV 值当作相同过滤条件的直接基线比较。

每个外层训练部分分别选择 cap=0.50 和 cap=1.00；模型、anchor、τ 网格及 tie-break 完全相同；在该折留出三元组上计量。没有从汇总留出曲线上挑新 TEST 策略。下表为全部配对，U/L₋ 使用 RR 单位，H 为百分数。

| 配对 | U，cap .50 | U，cap 1.00 | L₋，cap .50 | L₋，cap 1.00 | H%，cap .50 | H%，cap 1.00 |
|---|---:|---:|---:|---:|---:|---:|
| W-N | +0.003070 | +0.004063 | 0.004701 | 0.006269 | 14.956 | 16.799 |
| W-A | +0.001204 | +0.002078 | 0.001476 | 0.002481 | 3.746 | 4.627 |
| D-N | −0.000009 | −0.000009 | 0.000512 | 0.000512 | 1.647 | 1.647 |
| D-A | +0.000036 | +0.000071 | 0.000125 | 0.000135 | 0.093 | 0.114 |

放宽半径提高三组留出效用，同时提高这三组的无条件损失和受损频率；D-N 策略与结果相同。D-A 条件损失反而从约 0.13457 降至 0.11880，因此连 DEV 也不能把所有损害量说成同步增大。D-N 的负效用、正损失在点估计上被 Global 的零点支配。

| 配对 | 五折 β，cap .50 | 五折 β，cap 1.00 |
|---|---|---|
| W-N | .50, .50, .50, .50, .45 | 1.00, .85, .95, .85, .90 |
| W-A | .50, .50, .50, .50, .50 | 1.00, 1.00, 1.00, 1.00, 1.00 |
| D-N | .20, .20, .25, .20, .20 | .20, .20, .25, .20, .20 |
| D-A | .20, .50, .50, .30, .50 | .80, .80, .80, .95, .65 |

全部 40 个“折×家族”记录同时披露 τ、训练 MRR、留出风险和样本量。额外保存每组 21 个固定半径留出点（τ 固定为各折原选择），以及每组 84 个完整 DEV 拟合模型的 β×τ 点；后者明确标记 `full_dev_resubstitution`，不能充当留出性能。β=0 作为 Global 单独展示，不混入原非零半径的选参家族。

该结果提供了可审核的效用—损失取舍：保留 .50 的动作范围会牺牲三组的留出 MRR，并减少对应经验损失。它没有推导出唯一应选的风险容忍度，更不能在查看 TEST 后宣布 .50 是“最优保守半径”。

## 4. D08：共同参考下的完整取舍

所有原锁、模型、种子保持不变。TEST 汇总覆盖每组 12 个策略：Global、Relation、Query-soft、ADC、β=1、τ=0、R0、R1、R2、R3-fixed、R3、R4，共 48 个配对—策略行；另保留全部 seed/selector/direction 行。新图固定展示 Global、Query-soft、ADC、β=1、R3，论文共同表另加 Relation 与 τ=0，完整 CSV 不筛掉失败或较弱的 Dyna 变体。

应保留的结论：

- **Global：** 全部配对的参考相对损失为零，ADC 不可能在该量上优于它。D-N 中 Global 还拥有更高的观察效用；ADC 原有区间跨零，这里的支配只是点估计描述。
- **W-N Query-soft：** 当前 ADC 效用更高、受损频率更低，但无条件平均损失略高、条件损失更高。ADC 权重改变率较低（63.33% 对 79.79%），全体观测平均偏移却较高（0.12098 对 0.08257）。不能声称全面支配。
- **冻结 β=1：** ADC 四组的 H、L₋ 都较低，D-A 的 C 反而更高。四组的 Iα 完全相同；半径限制在这里减少的是偏移幅度，不是干预次数。MRR 的取舍因配对而异。
- **健康 R3：** ADC 四组的 H、L₋ 都较低，但 W-A、D-N、D-A 的 C 更高；R3 在 W-N、D-N 的 MRR 高于 ADC。
- **静态 Relation：** W-N 的效用更高（+0.004256），无条件损失也更高（0.014430）；它与 Global 一同保留，不能只展示不利于动态基线的比较。

图使用 U 对 L₋ 的共同坐标，点面积随答案排名改变率 J 增大；端点 anchor 三组加同一 Global/ADC/β=1 局部图，避免小差异被 Query-soft 的较大负效用压缩。J 不是完整排序干预率，也不是可跨规范化比较的权重率。
