# 论文推进汇报

## 1. 研究主题

当前论文拟聚焦：

**缺失视觉模态条件下多模态知识图谱补全中多模态收益边界的分析研究**

目前不再将论文主线设定为“提出一个全面更强的新模型”，而是将重点放在：

- 多模态信息在缺失视觉模态场景下是否稳定有效
- 关系感知融合与实体补偿分别起什么作用
- 多模态收益是否只存在于特定场景

## 2. 研究背景与动机

多模态知识图谱补全已经广泛使用文本与图像信息来增强实体表示。现有研究也已经关注：

- 缺失模态问题
- 关系感知融合
- 模态不均衡与模态鲁棒性

但从当前项目在 OpenBG-IMG 上的结果来看，多模态信息并不必然优于强结构基线。尤其是在缺失视觉模态、视觉质量不稳定的条件下，结构表示与多模态表示之间可能存在明显的竞争与边界效应。

因此，当前工作的研究动机已经从“设计一个更强模型”转向：

- 多模态何时有效
- 多模态为何失效
- 结构补偿为什么会压制多模态收益

这个研究方向更符合当前真实结果，也更适合 3–4 区期刊的稳健叙事。

## 3. 当前工作基础

### 3.1 模型与训练框架

当前项目已经形成一个相对完整的 MMKGC 实验框架，核心包括：

- 固定 `ComplEx` 解码器
- 文本模态与图像模态输入
- 关系感知门控融合
- 缺失视觉占位向量
- 图像模态 dropout
- 实体级补偿分支

同时，模型定义已经显式拆分为三类：

- `Gate-Only`
- `Residual-Only`
- `Gate+Residual`

这使得后续实验分析和论文叙事更加清晰。

### 3.2 输入特征流程

输入流程已经完成关键整改：

- 缓存原始文本特征与原始图像特征
- 模型内部加入可训练的文本投影层与图像投影层
- `build_model.py` 已支持优先读取 raw cache
- 旧版随机投影后冻结缓存的设定已不再作为主流程

这一步的完成，为后续实验结论提供了更合理的方法基础。

### 3.3 实验资产整理

当前已完成：

- 历史实验目录梳理
- 统一结果索引表
- baseline 口径整理
- 自动生成结果索引脚本

这使得后续实验能够在统一口径下持续积累和汇总。

## 4. 关键观察

### 4.1 强结构基线显著强于当前 full model

当前最关键的现象是：

- `Gate+Residual` 并没有稳定超过强结构基线
- `Residual-Only` 在现有结果中表现非常强
- 一些结构强基线如 TuckER、ComplEx 的结果也明显更高

这意味着当前项目不适合直接包装成“提出一个全面领先的新方法”。

### 4.2 问题不再主要来自输入流程

在完成 raw cache 与模型内可训练投影后，旧的“随机投影冻结缓存导致多模态分支天然吃亏”这个解释已经不是主要原因。

因此，后续真正要研究的是：

- residual 分支是否过强
- 融合分支是否未学到有效互补性
- 多模态收益是否只在局部成立

### 4.3 多模态收益可能具有明显边界

从当前结果趋势判断，多模态收益很可能并不是全局存在，而是具有明显边界，例如：

- 只在有图实体中存在
- 只在部分关系类型上存在
- 只在某些样本切片中存在

如果这一点能被实验证实，那么论文的核心价值就不在“方法领先”，而在“收益边界分析”。

## 5. 研究问题

当前论文拟围绕三个研究问题展开：

### RQ1

在缺失视觉模态条件下，多模态信息是否能够稳定提升 MMKGC 性能？

### RQ2

关系感知融合与实体补偿分别起什么作用，它们是互补还是竞争？

### RQ3

多模态收益是否具有明显的场景边界，例如仅在有图实体、某些关系类型或某些样本子集上成立？

## 6. 当前存在的问题

### 6.1 现有结果不支持“新方法全面领先”的叙事

当前 `Gate+Residual` 尚未证明自己能稳定优于：

- `Residual-Only`
- TuckER
- ComplEx

因此，论文必须避免预设“full model 一定最强”。

### 6.2 关键分析实验尚未完成

当前最关键但尚未系统完成的部分包括：

- `has_img` vs `no_img` 分组实验
- 按关系类型分组实验
- gate 分布分析
- residual scale / mix 行为分析
- 成功与失败案例分析

这些实验将直接决定论文最终的主线能否成立。

### 6.3 评测与汇报仍需进一步标准化

后续必须严格统一：

- train/dev/test 协议
- 多 seed 结果
- mean ± std 报告
- test 结果表

否则论文中的结论仍然会缺乏说服力。

## 7. 研究计划

### 第一阶段：协议与模型口径统一

目标：

- 统一五组主模型
- 统一 train/dev/test 流程
- 确认可训练投影和 raw cache 主流程稳定

主要产出：

- 统一配置
- 统一 baseline 定义
- 可复现实验入口

### 第二阶段：主实验重跑

目标：

- 形成规范主结果表

主要要求：

- 至少 3 个随机种子
- test 上统一汇报
- 报告 mean ± std

主模型组：

1. Text-only
2. Early Fusion
3. Gate-only
4. Residual-only
5. Full Model（Fusion + Residual）

同时保留强结构基线：

- ComplEx
- TuckER

### 第三阶段：核心分析实验

目标：

- 解释为什么多模态没有稳定带来收益

重点实验包括：

- `has_img` / `no_img` 分组实验
- relation type 分组实验
- gate 分布分析
- residual scale / 混合权重分析
- case study

### 第四阶段：论文写作

优先写：

- 引言
- 相关工作
- 实验设置
- 主结果

最后再写：

- 收益边界分析
- 讨论与结论

因为分析结果会决定整篇论文最终采用多强的“方法”语气。

## 8. 当前定性判断

从当前项目基础、真实结果、相关文献位置和投稿目标综合来看，最合理的论文主线不是：

- “提出一个更强的缺失视觉模态 MMKGC 模型，并超过现有方法”

而是：

- “在 OpenBG-IMG 上，以统一实验框架系统研究缺失视觉模态条件下多模态融合与结构补偿的作用关系，并揭示多模态收益的适用边界”

这条路线更真实、更稳健，也更容易形成一篇能投 3–4 区的论文。
