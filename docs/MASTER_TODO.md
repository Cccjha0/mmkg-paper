# 论文推进总 Todo

## 1. 文档说明

这份 Todo 基于以下文档整理而成：

- `docs/PAPER_PLAN.md`
- `docs/RESIDUAL_VS_FULL_TODO.md`
- `docs/ADVISOR_PROGRESS_REPORT.md`

目标不是重复已有计划，而是将现有判断进一步细化为可执行任务，便于后续逐项推进、打勾和复盘。

执行原则如下：

- 先修正方法与评测基础，再大规模补实验
- 不预设 full model 一定最强
- 不把零散实验结果直接写成论文结论
- 每一阶段都要有明确输出物
