# Paper Manuscript Directory

## Purpose

This directory is the unified working area for the paper main text.

The files in this folder are organized in manuscript order rather than experiment order.
They are intended to be the primary place for continued paper drafting and revision.

The original source drafts remain in `docs/` as backup materials:

- `INTRODUCTION_DRAFT.md`
- `RELATED_WORK_DRAFT.md`
- `TASK_AND_PROTOCOL_DRAFT.md`
- `MODELS_AND_METHODS_DRAFT.md`
- `MAIN_RESULTS_DRAFT.md`
- `GAIN_BOUNDARY_ANALYSIS_DRAFT.md`
- `BEHAVIOR_ANALYSIS_DRAFT.md`
- `CASE_STUDY_DRAFT.md`
- `DISCUSSION_LIMITATIONS_CONCLUSION_DRAFT.md`

## Writing Rule

Going forward, prefer editing the files in this directory when drafting the paper body.
Treat the original `*_DRAFT.md` files in `docs/` as source snapshots rather than the main manuscript.
