## Current paper positioning

The paper should be positioned as a **protocol-aware analysis-to-method paper**.

The analytical part establishes that multimodal gain on OpenBG-IMG is **bounded, conditional, and shaped by role--modality asymmetry**. The methodological part turns this diagnosis into **structured clean routing** for selective multimodal activation.

The current central claim is:

> Under the current OpenBG-IMG protocol, multimodal gain is not globally reliable. Naive clean routing with a single global threshold is too coarse, but structured clean routing and target-aligned clean supervision can recover additional deployable multimodal gain while remaining below Oracle routing.

## Current result line

Use the following result line as the current manuscript truth:

- The current OpenBG-IMG `paper_split` induces role--modality asymmetry: `head_has_img`, `head_no_img`, and `tail_no_img` are the meaningful target-side regimes.
- Naive single-threshold clean routing does not outperform the legal clean rule baseline.
- Direction-specific thresholding reaches about `0.2974` MRR and improves over the clean rule.
- Regression-based gain prediction reaches about `0.2982` MRR and is the strongest clean strategy.
- The best clean strategy improves over both the clean rule and `Residual-only`, with paired bootstrap confidence intervals strictly above zero.
- The best clean strategy remains below Oracle routing.

Do **not** use the older `0.3160 MRR / XGBoost + delta=0.01 + tau=0.7` result as the current main claim. That result belongs to an older or incompatible routing line unless it is explicitly revalidated and separately scoped.

## Current writing rules

### Rule 1: Keep evaluation lines separate

The paper uses three evaluation lines:

1. official model-comparison line;
2. clean routing line;
3. post-hoc analysis line.

Do not compare numbers across these lines as if they were generated by one aggregation basis.

### Rule 2: Preserve the clean legality boundary

Main deployable claims must use only legal query-time features:

- direction;
- relation identity;
- development-derived relation priors;
- observed-side modality indicators.

Do not use target-side image labels, true target identity, correct-target scores, or post-hoc expert outcomes as test-time clean-router features.

### Rule 3: Frame the paper as controlled, not universal

The paper should not claim universal multimodal superiority. The strongest claim is protocol-aware:

> Under this OpenBG-IMG protocol, structured clean routing recovers more deployable multimodal gain than naive clean routing, but a gap to Oracle remains.
