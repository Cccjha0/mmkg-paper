# B02：9／13 维匹配对照协议

2026-09-12，历史 TEST 已被查看后的补充诊断，不恢复确认性地位。仅使用 B07/C04 修正后、原始来源 hash 匹配的四主 pair 缓存，不重跑 scorer、不按 TEST 选择维度或修改主策略。

- 9 维为方向与两模型各四个统计量；13 维加四个 A−B 差值。除维度外，标签、去掉 endpoint RR ties、median imputer、StandardScaler、balanced/liblinear logistic、C=1、max_iter=2000 完全相同。两个维度采用同一个随机种子：完整 DEV 为 20260902，第 k 个零起始折为 20260902+10k+2。单 CPU 线程，无额外 C 搜索或早停。
- 共用原三元组关系分层五折（seed 20260901），同一 triple 的三基础 seed、双方向共同分组；同一训练部分的 21 点静态 anchor。每维 ADC 均搜索同样的 41 个动作：40 个原 beta/tau 组合和显式 Global；选择规则复用 matched_actions。每维另报告同一拟合对象上的 Query-soft，无额外动作搜索。
- 外折只在其训练部分拟合预处理、分类器和选择动作，再评估留出部分；全 DEV 拟合／选择分数标为 resubstitution，不冒充泛化性能。复用并验证原完整 DEV 的 13 维模型，重建原 20 个 13 维折模型作 replay；新增 20 个 9 维折模型与 4 个完整 DEV 模型。所有八个维度/pair 锁完成并绑定源文件后，独立 apply-test 阶段才能打开 TEST 行。
- 同时报告 pooled 与三 seed ×双方向的 MRR、相对 Global 效用、无条件平均损失、受损率及权重变化；报告 13−9 的配对点差，不新增显著性／全局优越主张。保留所有 pair、全部维度结果；不把 TEST 最好维度改为主方法。
- 对每折和完整 DEV/TEST 记录输入非有限数、列中位数插补后的差值依赖误差、浮点差值残差、13 维模型折叠为 9 维仿射系数的预测误差、迭代数、拟合样本数、条件数及 L2 几何。数学冗余指精确算术的仿射表示空间；有限精度残差不当作独立信号。列独立插补可能破坏依赖，单独记录。
- 不修改标准化、几何提取或历史模型代码。B01 的异常分数规则与 B03 的有限分数前提另以独立例子和实际函数测试核查；缓存的有限特征不能证明原始评分没有非有限值，因为旧几何函数会 sanitize。
