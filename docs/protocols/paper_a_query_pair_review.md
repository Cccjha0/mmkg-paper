# C11/C12 frozen diagnostic protocol

Written before this diagnostic run on 2026-09-12. Existing six pairs, three base seeds, two directions, five original DEV folds and all TEST policies remain fixed. This is retrospective evidence, not a new confirmatory test.

## C11: units and DEV sensitivity

Count a semantic query as `(direction, relation_id, known_entity)`: tail uses h, head uses t. Report both unique-key and answer-row denominators; do not count the three checkpoint repeats as three distinct semantic keys. A repeated key has more than one distinct gold answer. A cross-fold key occupies more than one original-triple fold. Separately count held-out rows whose key occurs in the corresponding outer training portion, by dataset/direction/fold. Verify dataset inventories and fold assignments across all three pairs. TEST key repetition and overlap with DEV are descriptive only.

Keep each original outer holdout H unchanged. From its outer training T remove every *whole original triple* that shares either `(tail,r,h)` or `(head,r,t)` with H. Retain all six seed/direction rows together. This direct purge guarantees that no held-out observable key occurs in the remaining combiner training data; it does not remove indirect graph dependence. Fit the original 13D balanced logistic recipe, anchor and 40 beta/tau resubstitution candidates on the remaining T. Compare with the original saved fit and one size-matched control per fold: retain the same number of T triples per relation as after purging, using SHA256 order of `2026091211|fold|h|r|t`. This control is a single fixed draw, not an estimate over random training subsets. Same classifier random state as the historical full-geometry fold: 20260902+(fold-1)*10+2. No inner-CV or extra policy-family search. Total 60 new small fits; all original 30 held-out outputs must replay. Report fold sample/class counts, selections, identity hashes, convergence, all three seed effects, MRR and losses relative to each procedure's own anchor. Compare methods on identical holdout rows. No full-DEV refit or TEST application follows this sensitivity. The frozen base experts were selected using full DEV, so this cannot establish end-to-end unseen-query generalization.

## C12: one paired TEST interval computation

Compute all 70 existing ADC-minus-method effects plus six full-minus-expanded-radius and six full-minus-no-fallback effects. All use exactly matched `(seed,direction,h,r,t)` observations. Expanded-radius sets beta=1 only; no-fallback sets tau=0 only; both keep the locked object/anchor and the stated non-finite fallback. R3 averages its three selector repetitions within an observation before pairing, matching the main estimand. Replay all old point estimates; do not choose a comparator or policy after inspecting an interval.

For each dataset sort original triples lexicographically, average the six paired differences within each triple, and draw N triples with replacement for each of 10,000 replicates. Use NumPy PCG64 with seed 2026091212 for MKG-W and 2026091213 for DB15K. The same draws serve all contrasts and pairs in that dataset. Report mean difference and two-sided 2.5/97.5 percentile endpoints with linear quantile interpolation. Save 82 effects, three paired seed means/sample SD (ddof=1), direction cells, cluster/order hashes, RNG and replicate count. Store only small summaries, not per-query results or bootstrap draw matrices.

Use the same implementation for DEV purge-minus-original, random-size-minus-original and purge-minus-random-size intervals, with 2,000 draws and seeds 2026091214/2026091215 by dataset. These condition on the fitted procedures and fixed training subsets; overlapping folds, developer adaptation and model fitting are not resampled. They are sensitivity summaries, not valid evidence that either procedure is equivalent or superior in a training population.

ADC-minus-Global on the four primary pairs is the central scientific contrast, but its historical TEST blindness was not established. Other pairs/comparators and the new sensitivities are exploratory. All intervals are pointwise and unadjusted for multiplicity; there is no familywise guarantee or confirmatory rejection count. Zero-containing intervals mean an effect is unresolved, not equivalence. A zero-width interval is reported only if paired outcomes are identical in this finite evaluated sample, which is separately checked. Main and complete paired-comparison tables use this unified run; old hash-bound interval receipts remain archived and any retained diagnostic table is explicitly historical.
