# D11/D12 frozen coverage and aggregation protocol

Recorded before this version's outcome calculation. Retrospective diagnostics only; no policy, radius, gate, score orientation, grid, or checkpoint selection. Retain all six pairs and both original grouped OOF DEV and locked TEST. Four-primary-pair aggregates are explicitly secondary descriptive summaries, not four independent datasets. Historical coverage artifacts remain a distinct, excluded version.

1. Replay the original corrected ungated **projected** proposal, reference and deployed action with the existing rejection replay. Recover the original balanced OOF margins from saved states; TEST uses saved margins. Confidence is `abs(2*expit(g)-1)`; no outcome or gold is an ordering input. Invalid rows must be counted; this diagnostic requires the previously audited finite scope.
2. A unit is `(base seed, fitted fold, direction, relation, known entity)`, shared across repeated observable queries. Strata are `(seed, fold, observable repetition count)`. Within each stratum sort descending unit-mean confidence; ties use a fixed pseudorandom key on canonically sorted units. Repeated exports can differ numerically (the first DEV replay exposed a confidence range of about 2.1e-8); report every cell's maximum range and count above 1e-12, and require identical projected actions within each unit. Averaging observed repetitions avoids choosing the first gold record as representative and does not refit the selector. The original observation-level scores remain unchanged for the AP audit. Two separate pools: **All** finite proposals, including zero movements, and **Active** nonzero ungated projected proposals. Neither pool means actual deployed gate coverage.
3. At predeclared deciles 0 through 10, accept `floor(decile*n_units_in_stratum/10)` whole units. Quotas make sets nested and match observation acceptance counts despite repetitions. This stratified batch diagnostic is distinct from a single streaming confidence threshold. Original gates/settings are not changed. Rejection returns to the anchor; acceptance keeps the exact raw projected weight.
4. Random reference: 512 independent uniform permutations within the same strata, each reused across all deciles. PCG64 seed `2026091200 + 4*pair_index + 2*split_index + pool_index`, indices in the declared order; tie key seed `2026091250 + 2*pair_index + split_index`. Each realization exactly matches the confidence acceptance count. Active-pool counts also match actual interventions. In All the actual intervention counts can differ. Report means of realized metrics and pointwise 2.5/97.5 randomization percentiles, **not population CIs or significance tests**. Conditional ratios are formed in each draw before averaging; do not replace these by ratios of expected counts. Also save exact expected additive totals to audit Monte Carlo arithmetic. Empty conditional metrics are undefined and valid draw counts are reported. No random draw is selected.
5. Per curve report full N; accepted, actual nonzero and harmed counts; `H_all=h/N`, `H_accept=h/n_accept`, `H_active=h/n_active`, actual intervention rate, net RR utility, unconditional loss and mean absolute movement. All-decile zero is Global; full acceptance is the original no-gate variant. For fixed proposals and nested sets the cumulative harm count and H_all are mechanically nondecreasing. Conditional risks need not be. Neither monotonicity nor lower full-denominator harm proves useful ordering. Active-only random matching limits the intervention-count explanation; direction and magnitude can still confound comparisons, so retain the existing shape-matched controls.
6. Primary **micro** curves pool additive counts across W-N/W-A/D-N/D-A and then divide. Full-denominator weights are `N_pair/sum N_pair`; accepted/active conditional weights are their own subset counts divided by corresponding pooled counts, varying by coverage and random draw. **Macro** means the arithmetic average of four pair-specific metric values (1/4 each); any undefined pair propagates, not silently omitted. Random aggregates are computed per realization before reporting randomization means/ranges. Do not bootstrap treating pairs as independent units. Verify exact duplicate observation keys between same-dataset pairs. Report pair counts, full-denominator weights, distinct dataset triples, and separate additional-pair curves.
7. Audit all 36 existing pair/split/action-population discrimination points against scikit-learn `average_precision_score` and the historical function. AP is non-interpolated, tie-grouped `sum((R_j-R_{j-1})*P_j)`, not trapezoidal PR area. AP lift is the **difference** `AP-prevalence`, shown in percentage points, not a ratio or percent relative improvement. Historical `auprc_risk_to_harm`/`auprc_lift_over_prevalence` CSV names map to AP and AP-minus-prevalence. Preserve immutable old artifacts. For the primary aggregate report macro AP (four APs averaged) and pooled AP (concatenate scores/labels and recompute), with the analogous prevalence and difference. Pooled AP is not a size-weighted average of pair APs, and cross-pair score comparison need not be calibrated. Aggregate APs are descriptive points; existing per-pair bootstrap CIs remain authoritative for their specified populations.

All new code, protocol, tests, old state/result identities, compact outputs and formal assets are hash-bound. Only offline CPU cache statistics are needed. No base scorer or model training is run. Reference definition: [scikit-learn average_precision_score](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.average_precision_score.html); the locally installed implementation/version is separately recorded.
